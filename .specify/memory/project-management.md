## 文档管理体系

### 关键文件

1. **constitution.md** (`/.specify/memory/constitution.md`)
   - 项目宪法，包含核心原则和治理规则
   - 具有最高权威性，所有开发必须遵循
   - 版本: 1.0.0 (2025-10-14)

2. **guifan.md** (`/guifan.md`)
   - 项目唯一最新规范源
   - 包含项目管理、开发、产品、安全等所有规范
   - 任何新规范都必须更新到此文件

3. **jindu.md** (`/jindu.md`)
   - 流水账式进度记录
   - 只增不改，按时间顺序记录
   - 格式: 时间戳、任务、进展、责任人、状态

4. **project-management.md** (`/.specify/memory/project-management.md`)
   - 项目管理记忆文档
   - 存储关键管理规则和配置
   - 用于项目重启后快速恢复上下文

### 文档更新规则

1. **进度更新**: 任何进展都要及时更新 `jindu.md`
2. **规范更新**: 新规范或规范变更都要更新 `guifan.md`
3. **记忆更新**: 重要的配置和规则要更新 `project-management.md`
4. **宪法更新**: 重大原则变更需要更新 `constitution.md`

## 技术栈记忆

### 核心技术
- **自动化框架**: Chrome MCP
- **富文本编辑**: 支持飞书文档格式
- **平台集成**: 各平台独立模块
- **数据安全**: 加密存储敏感信息

### 关键特性
- **可视化操作**: 用户能看到所有自动化操作
- **扫码登录**: 支持QR码登录，记住登录状态
- **配置透明**: 所有配置项可视化，支持"不需要"选项
- **实时状态**: 显示各平台发布状态
